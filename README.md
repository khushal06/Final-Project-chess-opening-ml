# Final-Project-chess-opening-ml- ITCS 3156 Final Project

**Sai Khushal Dulam | UNC Charlotte | May 2026**

## Overview
Predicting chess match outcomes using machine learning on 20,058 lichess games. Tests whether opening theory adds predictive power beyond player rating.

## Models
- Logistic Regression — 65.38%
- Random Forest — 66.93%
- XGBoost — 84.56%

## Files
- `Final_Project.ipynb` — full notebook with all code and results
- `games.csv` — lichess dataset

## How to Run
Open `Final_Project.ipynb` in Google Colab, upload `games.csv`, run all cells.

[Lichess Chess Dataset on Kaggle](https://www.kaggle.com/datasets/datasnaek/chess)
